# 色板使用说明

## 事实来源

色值只在 `palette.css` 里维护。本文件只讲分配方式，不复制色值。

## 亮暗映射

| 角色 | 浅色底 | 深色底 |
|---|---|---|
| 页面底 | paper | black |
| 卡片底 | 50 | 950 |
| 分隔线 | 150 | 850 |
| 正文 | 950 | 50 |
| 次级文字 | 600 | 400 |
| 弱化文字 | 500 | 500 |

切换时按上表整体平移，不要逐个颜色手调，否则深浅两套会失去对应关系。

## 语义色

红、橙、黄、绿、青、蓝、紫、粉八组各 11 级。默认只取 400（浅底）与 600（深底）两级：

| 语义 | 色组 | 说明 |
|---|---|---|
| 错误、删除 | red | 不用于强调普通按钮 |
| 警告、待处理 | yellow / orange | 两者不要同屏混用 |
| 成功、通过 | green | 只用于状态，不用于装饰 |
| 链接、信息 | blue / cyan | 二选一，全站统一 |
| 引用、标注 | purple / magenta | 用于边线与标签底 |

## 代码高亮

关键词、字符串、注释、函数、常量各分配一个色组，语法层级的区分靠色相，不靠明度。注释统一走中性 500 级，保证在两套底色下都退到背景后面。

## 对比度

低饱和是这套配色的特点，也意味着正文与底色之间余量不大。正文必须用 950/50 两端，次级文字不要低于 600/400。浅色底上的黄色、青色小字号文字容易不达标，只用于色块与大标题。

## 与 Minimal 主题的关系

Minimal 主题内置了对这套颜色的支持。在笔记应用里用它时，先关掉主题自带的强调色覆盖，再引入 `palette.css`，否则变量会被主题后加载的样式盖掉。
