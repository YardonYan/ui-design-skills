# 输入区与排队

输入区是这类界面里控件最密集的地方，也是最容易堆成一坨的地方。

## 基本状态

| 状态 | 界面要求 |
|---|---|
| 空闲 | 可输入、可加附件、能看到发送方式 |
| 有内容 | 发送与清空的动作明确区分 |
| 提交中 | 输入区不锁死，说清还能不能继续打字 |
| 排队中 | 显示队列长度与取消入口 |
| 后端不可用 | 说明原因与恢复方式，草稿保留 |
| 达到长度或附件上限 | 提前提示，不要等发送时才报错 |

## 附件

- 附件在发送前可预览、可单独删除。
- 展示处理状态：上传中、可解析、解析失败、类型不支持。
- 失败项不阻塞其他附件发送，也不静默丢弃。
- 大文件与图片分开表达，图片给缩略图，文件给类型与大小。

## 附加控件

模型选择器、斜杠命令、@ 提及、上下文标签这类控件，按使用频率分层：高频常驻，低频收进一个入口。不要同时展开四个浮层。

每个控件都要能用键盘打开、选择与关闭，浮层关闭后焦点回到触发位置。

## 发送语义

- Enter 发送、Shift+Enter 换行这类约定要在界面里可见，不要只写在文档里。
- 正在生成时按发送，界面要明说是「排队等上一条结束」还是「打断上一条」，不要两者都可能。
- 重发与编辑旧消息是两个动作，不要合并成一个按钮。
