# 分支与会话历史

对话不是一条直线。编辑旧消息重发、切换模型重试、并列比较两次回答，都会产生分支。

## 分支

| 项 | 要求 |
|---|---|
| 可见性 | 当前处于第几个分支、一共几个，位置固定且好找 |
| 切换 | 前后切换不改变其他分支内容，切回来滚动位置与草稿不丢 |
| 来源 | 说清分支从哪条消息分出来 |
| 编辑重发 | 明确标注原消息已被替换，历史里仍可查看原文 |

## 会话列表

- 标题从内容自动生成时，要允许用户改名；自动标题失败要有可读的兜底。
- 显示最近活动时间，而不是只显示创建时间。
- 删除与归档分开，删除给二次确认且说明是否可恢复。
- 搜索覆盖正文，不只对标题。
- 长列表分页或虚拟滚动，切会话时不要重置滚动位置。

## 移动端

小屏上分支切换与会话列表不能同时占据主视图。用抽屉或分层导航，返回时回到原来的消息位置。
