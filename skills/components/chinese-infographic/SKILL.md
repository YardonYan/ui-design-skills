# 中文可编辑 SVG 信息图

## 什么时候用

- 图要放进 PPT、Figma 或其他矢量工具继续调，不能是一张不可改的位图。
- 要画概念关系、知识地图、层级结构、流程或对比关系，节点与文字需要可选中、可改。
- 中文文案较长，需要避免文字溢出盒子、错行贴边。

不适用：产品功能插图、空状态插画；数据图表的模板选型；面向社群截图分发的竖版长图。

## 选型

- **概念/流程/生命周期/数据流**：clean-svg 单文件内联 SVG。
- **架构/服务/存储/信任分区**：architecture-svg，按组件类型分组着色。
- **要手绘白板风格、可协作编辑**：Excalidraw JSON；本库未收该格式模板时，先用内联 SVG 手绘风交付并标明限制。

## 中文排版规则

- **按中文字宽预留空间**：全角汉字按字号计宽，标点与英文按半角估算；文本盒宽度要放下最长一行，再留内边距。
- **文字内边距**：盒内文字四周至少留 24px，不让文字碰到边框；长词允许换行，盒高随之预留，不压到连线。
- 字号下限：标注文字 12px 以上，正文 16px 左右；小字投屏不可读时优先减少文字，不靠缩字号硬塞。
- 中英混排留盘古之白；不把 emoji 当功能图标。

## SVG 绘制规则

- 单文件 HTML，CSS 与 SVG 全部内联；无外部字体、JS、图片、渐变、发光与装饰色块。
- **连线先画、节点后画**，箭头位于盒子下层；有向连线 `fill="none"`，带 `marker` 箭头。
- **语义配色**：中性、输入、处理、存储、外部、风险各用一色，不沿彩虹序列逐节点变色。
- 节点控制在 5–9 个主元素内；关系复杂就分层或拆图，不把信息压进一张密图。
- 图例只在符号/颜色不显然时再加；形状、颜色都能自解释时不放图例。
- 导出用 SVG 矢量，不导出位图当主交付物。

## 内容纪律

- 节点名称、关系方向必须来自材料；推断出的关系标为「待确认」，不画成定论。
- 概念图与数据图分开：表达结构关系用本技能，表达数值比较走图表组件。

## 与相近技能的分界

| 手上的活 | 用 | 别走这份 |
|---|---|---|
| 可编辑矢量概念图/知识地图 | 本技能 | `spotkit`（确定性功能插图） |
| 数值图表模板与配色 | `lieflat-charts` | 本技能 |
| 竖版分享长图 | `infographic-poster` | 本技能 |
