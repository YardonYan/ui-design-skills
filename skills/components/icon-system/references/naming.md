# 命名、关键词与检索

## 文件名

- 用小写英文短词，多个词用连字符；一个图标一个文件。
- `_` 开头的文件是共享几何与零件，不是可直接使用的图标。
- 按主题分组，同组图标放在一起，方便对照线宽与圆角。

## 关键词

每个图标定义要带一组关键词，覆盖三种叫法：

| 类型 | 例子 |
|---|---|
| 物体本身 | 文件夹、信封、齿轮 |
| 动作或功能 | 下载、上传、同步、撤销 |
| 使用场景 | 审批、归档、通知 |

关键词用逗号分隔，避免只写一个同义词导致检索不到。多语言名字单独登记，不塞进文件名。

## 新增登记

1. 在同组索引里加一行，写文件名、一句话描述、关键词。
2. 检查是否已有语义相近的图标；重复比缺一个更麻烦。
3. 更新使用方展示页的顺序列表，不进列表的图标不会显示。
