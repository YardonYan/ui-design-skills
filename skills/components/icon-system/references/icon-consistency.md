# 成套图标的一致性规则

图标集的价值不在单个图标好看，而在放在一起像一家做的。下面几条是不变量，新增图标时逐条对照。

## 几何

| 项 | 约定 |
|---|---|
| 画布 | 统一坐标系，主体居中，四周留出一致的呼吸区 |
| 线宽 | 全组同一个描边宽度，不随图标大小缩放 |
| 圆角 | 全组同一套圆角半径，方体与圆体不混用 |
| 分层 | 后片、内容、前片三层，外描边落在最外层 |
| 细节 | 小于一个线宽的缝隙、尖角接缝处的毛刺一律不画 |

## 颜色

- 一套图标只从一个主色推导所有颜色：亮面、暗面、阴影、描边都是它的明度变体。
- 不引入第二个色相。语义色由使用方在使用时叠加，不写进图标定义。
- 亮暗两套底色都要核，浅主色上的标记最容易糊掉。

## 动效

- 悬停动作是物体本身会做的动作：翻开、抽出、旋转、压下，不是整体位移或淡入淡出。
- 动作只有静止与结束两个关键帧，中间由插值补齐；往复类动作结束时要平稳停下，不跳帧。
- 24px 与 28px 是必须过的两个尺寸；小于此尺寸仍要能辨认主体。

## 验收清单

1. 与同组三个相邻图标并排看，线宽、圆角、留白是否一致。
2. 换到另一套色板看，是否仍然成立。
3. 缩到 24px 看，细节有没有糊成一团。
4. 静止帧、悬停帧、悬停中间帧各截一张，检查有没有跳帧与描边露头。
5. 导出静态 SVG 后，确认不依赖外部脚本与样式表也能独立渲染。

## 常见偏差

- 为了区分语义给单个图标换了色相：整组立刻失去一致性，语义交给外层容器表达。
- 新图标照着别的图标集画：几何不变量对不上，一眼能看出是拼接的。
- 只在浅色底上验收：暗色底上阴影与内发光方向会反过来。
