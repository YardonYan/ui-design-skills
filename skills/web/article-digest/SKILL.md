# 长文一页摘要

## 什么时候用

- 一篇长文/报告读完没时间精读，只要核心结论与关键要点。
- 要把文章精华做成一页可转发的材料，读者不点开原文也能抓住重点。
- 公众号长文、会议报告、调研文章的二次提炼。

不适用：保留全部摘录与个人思考的读书笔记；讲清一个陌生概念；杂志编辑感的长图海报。

## 固定结构

1. **核心结论**：一段话前置，先说文章最终主张了什么。
2. **要点清单**：3–5 条，每条一个小标题加一句解释，按重要性排序。
3. **关键数据/引用**：支撑结论的数字与原话，标明来自原文。
4. **适用场景或行动建议**：这篇内容对谁有用、可以怎么用；材料没有建议就不写。
5. **来源**：原文标题、作者、链接或出处与整理时间。

## 压缩纪律

- **不失真**：概括不得改变原意；弱化、反转或拔高结论都算失真。
- **摘录与概括分区**：原话引用单独成组并加引号，自己的概括明确标为「摘要」，不混排。
- **不补造**：材料里没有的数据、案例与评价不补；信息不足时缩短要点，不扩写。
- 篇幅控制在一页内；超长原文先分段提炼，再合成一页，不堆成第二屏。

## 产出约束

- 单文件 HTML，样式内联，无外部图片与 CDN；图示用内联 SVG/CSS。
- 结论与要点用字阶区分，不靠整屏彩色；窄屏可正常重排。
