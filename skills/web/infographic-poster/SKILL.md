# 竖版信息长图

## 什么时候用

- 一组要点（培训要点、活动流程、步骤清单、结论合集）要发群里/朋友圈，别人不用点开就能看完。
- 内容是并列的一组条目，不需要交互与跳转，目标是一图读完。
- 成品要能直接截图分发，或导出 PNG/PDF。

不适用：杂志报纸全版那种编辑感长文；需要强烈视觉冲击的单张主视觉；需要可编辑矢量图形、放进 PPT 继续调的信息图。

## 布局

1. **顶部**：主题标签 + 超大标题，一句话说清这张图讲什么。
2. **中部**：编号要点区块，一块一个要点；标题 + 一两句解释，配编号、图标或短分隔线。
3. **底部**：CTA、来源或署名；二维码/占位用 CSS 色块或内联 SVG 绘制，不引外链图片。

## 尺寸与排版

- 默认竖版 1080×1920；A4 竖版/横版按需选择。
- 内容必须完整落在目标尺寸内，页面不滚动；字号与间距用 `clamp()` 或固定 px，都要保证目标尺寸下无溢出、不贴边。
- 配色克制：主色 + 中性色 + 不超过一个强调色；不用占位文字与 lorem ipsum。

## 导出与截图纪律（第三方技能踩过的坑）

- **截图/导出脚本不能写死他人电脑上的绝对路径**。输入输出路径必须参数化或走相对路径；换一台机器脚本仍能跑。
- 说明里写「环境已装好无需安装」时，先核对本机是否真具备对应环境，不要直接采信。
- 网页本身先直接打开确认排版无误，再手动截图；导出脚本依赖无头浏览器时，本地图片必须走相对路径、经本地 HTTP 服务加载。
- 脚本与产物分离：截图工具放 `scripts/`，不要把路径常量硬编码进页面样式。
