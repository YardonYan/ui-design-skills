# 概念讲解一页

## 什么时候用

- 别人问「XX 到底是什么」，回复不想写成一大段纯文字。
- 要把一个陌生概念给同事、客户或学习者一次讲明白，读完能复述大意。
- 需要一页可转发、可双击打开的讲解材料，而不是聊天记录里的长段说明。

不适用：卖产品、引导注册的落地页；多章节、带侧导航的长文档；需要实时数据的看板。

## 固定结构

按下面六段组织，缺素材的段落先标「待补充」，不要硬编内容：

1. **概念名 + 一句话定义**：标题是概念名；定义不超过两行，先给「是什么」，再给「属于哪一类」。
2. **类比区**：一个日常类比，把抽象概念落到听众熟悉的事物上。类比后面必须补一句「类比在哪里失效」，避免误导。
3. **要点拆解**：3–5 条核心要点，每条一个小标题加一句解释，不堆术语。
4. **最小例子**：一个能跑通的小例子、对照或三步流程，让人看到概念怎么用。
5. **边界与常见误解**：澄清容易混淆的说法，写清这个概念不包含什么。
6. **术语脚注**：首次出现的专业词就地解释；延伸出处放页脚紧凑元数据块。

## 写作纪律

- 术语首次出现必须配一句白话解释；同一段里不连续抛三个以上未解释的术语。
- 定义、例子、数字必须有据；材料里没有的论点和数字不补，不足就如实说明。
- 类比要贴切，并指出失效处；不用比喻替代定义。
- 正文可读优先：字阶靠字号与字重区分，不靠颜色堆满；中英混排留盘古之白。

## 产出约束

- 单文件 HTML，CSS/JS 全部内联，不引外部 CSS、JS、字体与图片；任何浏览器直接打开。
- 不使用 lorem ipsum 与占位文案；图示用内联 SVG 或 CSS 绘制。
- 移动端窄屏（≤920px）能正常重排，不出现横向滚动。

## 与相近技能的分界

| 手上的活 | 用 | 别走这份 |
|---|---|---|

| 长文压成一页结论摘要 | `article-digest` | 本技能（本技能面向概念，不面向原文压缩） |
