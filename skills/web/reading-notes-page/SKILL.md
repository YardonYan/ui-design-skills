# 读书笔记页

## 什么时候用

- 读完一本书，想留一份能翻的笔记，过半年还能想起它讲了什么。
- 一篇长文/报告做了划线和批注，要整理成可归档、可转发的 HTML 页面。
- 已有笔记数据（摘录、思考），需要一份有固定结构、像写完的笔记而不是原始导出的成品页。

不适用：产品说明/开发文档站；只要一页核心结论的摘要；需要登录阅读平台拉取数据的脚本流程（本技能只整理已提供的材料）。

## 生成前先体检

动笔前先核对材料里有没有这几类内容，缺项先列出来向用户确认，不要猜：

- 书名/文章标题、作者、来源
- 摘录或划线原文
- 个人思考、批注或书评
- 时间、版本等元信息

材料为空或只有标题时，先报告「当前账号/材料里没有可整理的摘录」，不要用占位文字凑版面。

## 固定结构（八段）

1. **书目信息**：标题、作者、来源、导出时间、可定位的标识。
2. **笔记统计**：摘录条数、思考条数等可从材料算出的计数。
3. **一句话综述**：基于已有摘录与思考写出的整书/全文回顾，先给结论。
4. **导语**：一段读起来像写完的笔记，交代这本书/文章在讲什么、适合谁读。
5. **章节分组摘录**：按章节或主题分组，原文逐条保留，配小节标题。
6. **个人思考/书评**：用户批注与综合评价，与摘录分区呈现。
7. **金句/重点标记**：被反复划线的句子单独成组。
8. **来源与元数据**：紧凑的来源、口径与调试信息块，不占主版面。

## 内容纪律

- **区分摘录与综述**：原文摘录保持原样（只做空白清理与 HTML 转义）；综述、联想、评价明确标为「我的思考」，不混进引文。
- **不补造内容**：综述不得引入材料里没有的情节、论点、人物或数字；材料不足就缩短综述，不扩写。
- **歧义先列出**：标题对应多个版本/篇目时，给出候选清单让用户确认，不替他猜。
- 摘录与思考的归属要可追溯：哪条来自原文、哪条是批注，版面层级上分得开。

## 产出约束

- 单文件 HTML，样式内联，不引外部图片与 CDN；配图用纸色块、1px 墨线或内联 SVG。
- 长文阅读优先：正文行高 1.5–1.55，标题与正文用字阶和留白区分，不靠彩色堆满。
- 适合 A4 打印时，标题不与正文跨页分离，摘录行不被截断。
