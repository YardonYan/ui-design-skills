# 隐私与许可口径

## 不出现什么

对外公开库里不出现三类实体信息：真实姓名、真实公司名、真实雇主相关的组织名称与内部系统名。技能文档里写`示例企业``业务方``某中后台系统`，不写具体实体。

判定方式是机器扫描而不是人工记忆。`tools/scan_sensitive.py` 对全库文本文件跑模式匹配，命中即返回非零退出码；推送前跑一次是硬性步骤。

## 保留什么

- 技术名词、框架名、开源项目名、上游仓库 URL 全部保留。
- GitHub 账号标识只出现在链接与版权行里，属于已经公开的项目归属，不视为私人身份信息。
- 上游作者的公开署名与版权声明保留，这是 MIT / Apache-2.0 / CC BY 4.0 的许可义务，不能因为脱敏删掉。

## 收录边界

| 来源 | 处理方式 |
|---|---|
| 自有技能与文档 | 全量收录，Apache-2.0 |
| MIT / 0BSD / Apache-2.0 / CC BY 4.0 上游 | 原样收录正文，保留各自 LICENSE 与 CONTRIBUTORS |
| source-available 或条款不明的技能文档 | 不收录正文，只留链接与一句说明 |
| 私有库的公司专用命名空间 | 整块排除，与 UI 抽取无交集 |

私有库里另有公司专用内容与记忆快照，两者都不进公开库。抽取时按技能目录白名单复制，不按整库复制，避免顺手带出无关文件。

## 改动上游内容时

改了第三方技能的正文，要在该技能的 `SOURCE.md` 里注明改了什么。Apache-2.0 要求标注修改过的文件，MIT 与 0BSD 要求保留版权声明。逐条义务见 `THIRD-PARTY.md`。
